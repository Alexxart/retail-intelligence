# Stage 4 — автономный интерфейс
HTML содержит встроенные данные и собственные SVG-графики; нет CDN, сетевых запросов и внешних шрифтов. Продажи фильтруются по месяцу, региону магазина, каналу и категории. Заказы считаются уникальными; средний чек при фильтре категории — выручка выбранной категории на содержащий её заказ, не полный чек. Клиентские сегменты пересчитываются внутри выборки на конец выбранного периода; повторность означает два и более заказа в выборке. Когорты фиксированы на полном горизонте. Факторный мост фиксирован на 2024–2025. Складские показатели фильтруются только по периоду и категории; регион продаж и канал не применяются. ABC/XYZ фиксированы на полных календарных годах, категория ограничивает отображаемые SKU. Логистика фильтруется по периоду, региону продаж и каналу, не по категории. Складские обороты и GMROI не годовые при неполном периоде. DIO использует фактическое число дней. Ограничения Stage 2 сохраняются.

## Проверки
Chromium через Playwright: загружено содержимое HTML без сети, четыре вкладки, комбинированный фильтр, сброс, обратный интервал, сверка годовой выручки, прибыли и числа заказов с SQL/Python. Ошибок JS не зарегистрировано. Полноразмерные снимки в images/dashboard_1.png–dashboard_4.png. Прямой file:// заблокирован политикой среды; тест выполнен через set_content. PostgreSQL не запускался. Не проводилось исчерпывающее тестирование всех комбинаций фильтров и браузеров.
